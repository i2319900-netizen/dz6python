# Python functions

- `sum_distance(from_, to)` считает сумму целых чисел от `from_` до `to`.
  Если границы переданы в обратном порядке, функция сама меняет их местами.
- `trim_and_repeat(s, offset=0, repetitions=1)` отрезает от строки первые
  `offset` символов и повторяет остаток `repetitions` раз. Оба параметра
  можно не указывать.

В конце файла примеры вызова функций с ожидаемым результатом в комментариях.
